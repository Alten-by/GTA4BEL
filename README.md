# Беларуская лакалізацыя Grand Theft Auto IV

Беларуская лакалізацыя для Grand Theft Auto IV. Замяняе тэкст і шрыфты ў рускім слоце гульні.

Пераклад тэксту выкананы нейрасеткай Claude.

> Grand Theft Auto IV © Rockstar Games. Гэты праект неафіцыйны і не звязаны з Rockstar Games. Для выкарыстання патрэбна набытая копія гульні.

## Што ў рэпазіторыі

```text
common/
  data/
    fonts_r.dat
  text/
    russian.gxt
pc/
  textures/
    fonts_r.wtd
    fonts_r_streamed_1.wtd
tools/
  xcs/
    american.xcs
    bel.xcs
```

| Файл | Што гэта |
|---|---|
| `common/text/russian.gxt` | Тэкст лакалізацыі. |
| `common/data/fonts_r.dat` | Табліца адпаведнасці сімвалаў і ячэек гліфаў. |
| `pc/textures/fonts_r.wtd` | Асноўная тэкстура шрыфту. |
| `pc/textures/fonts_r_streamed_1.wtd` | Дадатковая (streamed) тэкстура шрыфту. |
| `tools/xcs/bel.xcs` | Профіль гліфаў для беларускага тэксту. |
| `tools/xcs/american.xcs` | Профіль гліфаў для англійскага тэксту. |

## Усталяванне

1. Спампуйце `belarusificator-setup.exe` з раздзела **Releases** гэтага рэпазіторыя.
2. Закрыйце GTA IV.
3. Запусціце ўсталёўшчык і выберыце папку з `GTAIV.exe`.
   - Steam Complete Edition: `...\Grand Theft Auto IV\GTAIV`.
4. Уключыце ў гульні рускую мову: лакалізацыя замяняе рускі слот.
5. Запусціце гульню.

Усталёўшчык сам стварае рэзервовыя копіі. Каб вярнуць арыгінальныя файлы, скарыстайцеся uninstaller.

## Ручная ўсталёўка

Калі не хочаце выкарыстоўваць усталёўшчык:

1. Зрабіце рэзервовую копію арыгінальных файлаў гульні.
2. Скапіруйце файлы з рэпазіторыя ў папку гульні з захаваннем структуры.
3. У Steam Complete Edition папка гульні — `...\Grand Theft Auto IV\GTAIV` (там, дзе знаходзіцца `GTAIV.exe`).
4. Уключыце ў гульні рускую мову.
5. Запусціце гульню.

Каб вярнуць арыгінальныя файлы, аднавіце іх з рэзервовай копіі.

## fonts_r.dat

`fonts_r.dat` — гэта тэкставы файл у кадзіроўцы Windows-1251. Гэта не самі гліфы, а табліца, якая паказвае, які сімвал якой ячэйкай тэкстуры малюецца.

- Файл складаецца з некалькіх блокаў `[MAP] ... [/MAP]`.
- У блоках ёсць радкі-каментарыі (`#`) і радкі з лікамі.
- У кожным радку з лікамі звычайна 16 значэнняў.
- Кожны лік — індэкс ячэйкі гліфа ў адпаведнай тэкстуры `.wtd`.
- Розныя блокі `[MAP]` адпавядаюць розным стылям і памерам шрыфту.

Ячэйкі ў тэкстуры памерам 1024×1024 маюць памер 64×64 і размяшчаюцца сеткай 16×16:

```text
x = (n % 16) * 64
y = (n / 16) * 64
```

Дзе `n` — лік з `fonts_r.dat`.

Што важна:

- не змяняйце колькасць блокаў, радкоў і значэнняў;
- не змяняйце кадзіроўку файла (Windows-1251);
- каментарыі не ўплываюць на гульню, але дапамагаюць знайсці патрэбны сімвал;
- пасля змен праверце вынік у гульні.

Каб змяніць **выгляд** сімвала, змяніце лік на іншы індэкс ячэйкі. Каб змяніць **сам гліф**, трэба правіць адпаведны файл `.wtd`.

## .wtd

`fonts_r.wtd` і `fonts_r_streamed_1.wtd` — гэта RenderWare Texture Dictionary з тэкстурамі шрыфтоў.

- Памер тэкстуры: 1024×1024.
- Фармат: DXT5.
- Сетка: 16×16 ячэек па 64×64 пікселі.
- `fonts_r.wtd` — асноўная тэкстура шрыфту.
- `fonts_r_streamed_1.wtd` — дадатковая (streamed) тэкстура шрыфту.

Як правіць:

1. Зрабіце рэзервовую копію файла `.wtd`.
2. Адкрыйце файл у рэдактары WTD, які падтрымлівае GTA IV (напрыклад, OpenIV або іншы).
3. Экспартуйце патрэбную тэкстуру або ячэйку ў DDS/PNG.
4. Адрэдагуйце гліф, захоўваючы памер ячэйкі 64×64 і альфа-канал.
5. Імпартуйце тэкстуру назад і захавайце `.wtd` у тым жа фармаце (DXT5, 1024×1024).
6. Праверце, што `fonts_r.dat` паказвае на правільныя ячэйкі.
7. Запусціце гульню і праверце вынік.

Не змяняйце памер тэкстуры, колькасць ячэек і фармат без неабходнасці. Кожны гліф павінен заставацца ў межах сваёй ячэйкі і не перакрываць суседнія.

## Як змяняць тэкст

Для рэдагавання тэксту выкарыстоўвайце **X GXT Editor V.2.3**. Ён падтрымлівае імпарт карыстальніцкіх абазначэнняў гліфаў (`.xcs`), каб у рэдактары літары паказваліся правільна.

У рэпазіторыі ёсць два профілі:

- `tools/xcs/bel.xcs` — для беларускага тэксту;
- `tools/xcs/american.xcs` — для англійскага тэксту.

Напрыклад, калі ў `bel.xcs` ячэйка 112 пазначана як `У`, рэдактар будзе паказваць `У`, а не іншы сімвал.

Як правіць:

1. Зрабіце рэзервовую копію `.gxt`.
2. Адкрыйце X GXT Editor V.2.3.
3. Адкрыйце патрэбны `.gxt` (беларускі — `common/text/russian.gxt`).
4. Імпартуйце адпаведны `.xcs`: для беларускага — `bel.xcs`, для англійскага — `american.xcs`. (`.xcs` трэба пакласці ў папку `fonts` рэдактара)
5. Рэдагуйце тэкст.
6. Захавайце `.gxt`.
7. Запусціце гульню і праверце.

Калі `.xcs` не выбраны, у рэдактары могуць паказвацца не тыя літары: гэта не пашкоджанне тэксту, а розніца ў кадаванні гліфаў. `.xcs` — толькі дапаможнік для рэдактара; у гульні выкарыстоўваюцца `fonts_r.dat` і `.wtd`.

## Частыя пытанні

**Тэкст застаўся рускім.**

Праверце, што ў гульні ўключана руская мова і файлы скапіраваны ў патрэбны слот: `common/text`, `common/data`, `pc/textures`.

**Сімвалы пустыя або не тыя.**

Праверце `fonts_r.dat` і адпаведны `.wtd`: індэксы ячэек, кадзіроўку і фармат тэкстуры.

**Ці падыходзіць для Steam Complete Edition?**

Так, калі гульня ўключана на рускай мове. Папка з `GTAIV.exe` у Steam — `...\Grand Theft Auto IV\GTAIV`.

**Ці можна выкарыстоўваць на іншых версіях гульні?**

Магчыма, але патрэбна праверка: структура слотаў і шрыфтоў у іншых версіях можа адрознівацца.
